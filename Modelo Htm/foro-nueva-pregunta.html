Consejos para una buena pregunta

  • Usa un título claro y específico
  • Describe el problema con detalle
  • Menciona lo que ya intentaste
  • Incluye código o capturas si aplica
  • Revisa la ortografía antes de publicar
  • No hagas múltiples preguntas en un mismo post
  • Evita títulos como "ayuda" o "no funciona"
